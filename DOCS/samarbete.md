# Samarbete i gemensamt repository 
Ett gemensamt repository fungerar som en central, delad plats där hela utvecklingsteamet lagrar och synkroniserar sin kod. Istället för att skicka filer fram och tillbaka manuellt kan varje teammedlem hämta den senaste versionen av koden som andra lagt till, göra sina egna ändringar och sedan skicka upp dem till det gemensamma repot. På så sätt kan flera personer arbeta parallellt utan att skriva över varandras arbete, ofta genom att jobba i olika branches som senare slås ihop. Repositoryt bevarar också hela historiken över vem som gjort vilka ändringar och när, vilket gör det enklare att spåra buggar eller gå tillbaka till en tidigare version om något går fel. På det sättet blir det möjligt för teamet att jobba strukturerat och spårbart på samma projekt samtidigt, istället för att koden blir en röra av manuellt utbytta filer.
